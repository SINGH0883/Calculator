## 🌟 Overview

**NeoCalc Pro** is an advanced, responsive web-based **Scientific Calculator** engineered for students, engineers, and scientists. Featuring a cyberpunk glassmorphic dark interface with 5-column ergonomic layout, dynamic 2nd function toggling, degree/radian mode switching, and comprehensive mathematical routines.

---

## ⚡ Scientific Calculator Capabilities

* **📐 Trigonometric Suite:** 
  * Standard: `sin`, `cos`, `tan`
  * Inverse (`2nd` Mode): `sin⁻¹` (asin), `cos⁻¹` (acos), `tan⁻¹` (atan)
  * Angle Toggle: **`DEG` (Degrees)** & **`RAD` (Radians)** mode selector
* **📈 Logarithms & Exponents:** 
  * Natural logarithm (`ln`), Base-10 logarithm (`log`), Exponential ($e^x$), Base-10 power ($10^x$)
* **🔢 Powers, Roots & Factorials:** 
  * Custom Exponentiation ($x^y$), Custom Root ($^y\sqrt{x}$), Square ($x^2$), Cube ($x^3$), Square Root ($\sqrt{x}$), Cube Root ($\sqrt[3]{x}$), Factorial ($n!$), Reciprocal ($1/x$)
* **🧮 Mathematical Constants:** 
  * $\pi$ (Pi = 3.14159265...) & $e$ (Euler's Constant = 2.71828182...)
* **💾 Memory Management System:** 
  * Memory Clear (`MC`), Memory Recall (`MR`), Memory Add (`M+`), Memory Subtract (`M-`) with active indicator badge
* **📊 Dual Expression Display:** Real-time formula context (`subDisplay`) showing step-by-step calculations.
* **⌨️ Physical Keyboard Support:** Full hotkey bindings for standard number pads, arithmetic operators, parentheses `()`, and functions.

---

## 🛠️ Tech Stack

* **Structure:** HTML5 Semantic Elements
* **Styling:** CSS3 Custom Properties, Glassmorphism backdrop filters, Google Fonts (`Outfit` & `Fira Code`)
* **Engine:** Vanilla JavaScript (`ScientificCalculator` ES6+ Class Engine)
