## 🌟 Overview

**NeoCalc** is a modern, responsive web-based calculator designed with a futuristic dark mode aesthetic, vibrant neon accents, floating ambient background light orbs, and glassmorphic card design.

---

## ⚡ Key Features

* **💎 Cyberpunk Glassmorphism UI:** Multi-layered blurred background (`backdrop-filter: blur(25px)`), animated floating light orbs, and subtle glowing borders.
* **📊 Dual-Row Expression Display:** Shows previous expressions (`subDisplay`) alongside current numerical inputs for maximum calculation context.
* **🔢 Scientific Utility Functions:** Supports percentage calculations (`%`), sign negation (`±`), floating-point decimal precision, and clear/backspace routines.
* **⌨️ Complete Physical Keyboard Integration:** Full support for standard numeric keypads, arithmetic operators (`+`, `-`, `*`, `/`), `Enter`/`=`, `Escape` (`AC`), and `Backspace`.
* **📱 Fully Responsive Design:** Fluid layouts optimized for mobile devices, tablets, and desktop displays.

---

## 🛠️ Technology Stack

* **Structure:** Semantic HTML5
* **Styling:** Vanilla CSS3, Custom Properties (Variables), Flexbox, CSS Grid, Glassmorphism, Google Fonts (`Outfit` & `Fira Code`)
* **Logic:** Vanilla JavaScript (ES6+ Object-Oriented `Calculator` class)
